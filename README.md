# DevSamadhan-Feedback

Public feedback and editorial issue tracking for [DevSamadhan](https://dev-samadhan-three.vercel.app/).

## Purpose

This repository collects feedback on DevSamadhan's competitive-programming problem pages -- incorrect code, unclear explanations, complexity errors, source-attribution issues, and accessibility concerns.

It does **not** contain the application source code.

## How to report an issue

1. Click **Issues** > **New issue**.
2. Select the **Problem Feedback** template.
3. Fill in the category, problem name, and a clear description.
4. Submit the issue.

Reports are reviewed by the DevSamadhan maintainers. Please keep reports factual and concise.

> **Warning: Public visibility**
>
> All issues are public. Do not include personal data, credentials, secrets,
> or security-sensitive information.
